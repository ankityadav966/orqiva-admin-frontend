# ORQIVA Tech — Enterprise Admin Panel Frontend

Modern, high-performance Next.js Admin Dashboard and Content Management System (CMS) custom-built for **ORQIVA Tech**.

---

## 🎨 Theme & Brand Aesthetics

- **Dark Enterprise Palette:** Built with `#0B1220` deep slate background and `#111C2E` / `#1E2D4A` cards.
- **Brand Accents:** `#FF6A21` / `#FF8336` gradient glows matching ORQIVA Tech's identity.
- **Modern Typography:** Outfit & Plus Jakarta Sans with refined line-height and micro-animations.
- **Instant Feedback:** Sonner toast notifications, responsive slide-out modals, and delete safety confirmations.

---

## 🚀 Key Features & Modules

1. **Dashboard Overview (`/dashboard`):** 8 primary KPI metric cards, Homepage Counters preview, Recent Inquiries & Leads feed.
2. **Hero Section Manager (`/dashboard/homepage`):** Heading, subheadings, dynamic rotating typing words, CTA buttons, trust badges, and hero showcase visuals.
3. **Company Statistics (`/dashboard/statistics`):** 100+ Clients, 500+ Projects, 10+ Countries, 99% Satisfaction counters with order control.
4. **"Currently Building" Featured Project (`/dashboard/featured-project`):** Dynamic project badge displayed across the public homepage hero.
5. **Services CMS (`/dashboard/services`):** Full CRUD for Website Development, Mobile Apps, ERP Systems, AI Solutions, Cloud DevOps, and Digital Marketing with capabilities tags and color pickers.
6. **Industries CMS (`/dashboard/industries`):** Complete management for Healthcare (40+), Education (55+), Finance (30+), Retail (65+), Manufacturing (25+), Real Estate (35+), Travel (20+), Government (15+), emoji glyph pickers, and project counts.
7. **Portfolio Projects (`/dashboard/projects`):** Project case studies, deliverables, screenshots, categories (Web App, ERP, E-Commerce, Mobile, AI, CRM), and live URLs.
8. **Technology Stack (`/dashboard/technologies`):** Technologies categorised across Frontend, Backend, Mobile, Cloud, DevOps, Database, and AI.
9. **Clients & Partners (`/dashboard/clients`):** Client roster, logo uploads, and website URLs.
10. **Testimonials & Reviews (`/dashboard/testimonials`):** Client feedback, 1–5 star ratings, executive avatars.
11. **Blog CMS (`/dashboard/blog`):** Articles, Markdown content, categories, author bio, tags, reading time, and publication statuses (Draft, Published, Archived).
12. **FAQs Manager (`/dashboard/faqs`):** Frequently Asked Questions categorized by Services, Pricing, Process, and SLA.
13. **Careers & Talent CRM (`/dashboard/careers`):** Job vacancy board + incoming candidate applications reviewer.
14. **Leads CRM (`/dashboard/leads`):** Inbound quote requests, demo bookings, and consultation leads pipeline, internal team notes, and CSV export.
15. **Contact Inquiries (`/dashboard/contact`):** Submissions from the Contact Us page, status tracking, and 1-click email reply.
16. **Newsletter Subscribers (`/dashboard/newsletter`):** Audience captured from the footer with CSV export.
17. **Media & Asset Library (`/dashboard/media`):** Drag-and-drop file uploader, image previews, and 1-click URL copying.
18. **Website Settings (`/dashboard/settings`):** Company profile, social media links, global SEO tags, and footer information.
19. **Navigation Menu (`/dashboard/navigation`):** Top navigation routes and ordering.
20. **Admin Profile & Security (`/dashboard/profile`):** Account information update and encrypted password change.

---

## 🛠️ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env.local

# 3. Start development server (Port 3000)
npm run dev

# 4. Build for production
npm run build
```
